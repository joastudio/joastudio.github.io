좋아알림 · 시행일 2026년 10월 21일

개인정보 처리방침

좋아알림(이하 "앱")은 좋아스튜디오(JOASTUDIO)가 만든 Android 앱으로, 사용자가 선택한 앱의 알림 중 사용자가 정한 조건에 맞는 알림을 골라 소리·진동·음성과 화면 알림으로 알려 줍니다. 아래 내용은 앱이 기기 안에서 처리하고 보관하는 정보를 설명합니다.

목차 처리하는 정보와 목적 기기에 저장하는 정보 외부 전송과 제3자 제공 다른 앱과의 연동 접근 권한 보관 기간과 삭제 처리방침 변경 문의
좋아알림은 회원가입이 없고 인터넷 권한을 사용하지 않습니다. 알림은 모두 기기 안에서 처리하며 개발자를 포함한 누구에게도 보내지 않습니다. 광고·분석·오류 보고 도구도 포함하지 않습니다.

1. 처리하는 정보와 목적

앱은 Android의 알림 접근 권한으로 받은 알림 중 사용자가 감시할 앱으로 선택한 앱(현재 카카오톡)의 알림 본문만 읽습니다. 읽은 본문은 사용자가 정한 화물 조건이나 키워드에 맞는지 판단하는 데에만 사용합니다. 선택하지 않은 앱의 알림은 처리하거나 저장하지 않습니다.

알림 본문에는 대화방의 다른 참여자가 작성한 글과 전화번호 같은 다른 사람의 정보가 포함될 수 있습니다. 이 정보도 위 목적에만 사용하며 기기 밖으로 보내지 않습니다.

2. 기기에 저장하는 정보

항목내용
최근 알림 이력 조건에 맞은 알림의 본문, 알림을 보낸 앱, 받은 시각(최근 100건)
사용자 설정 화물 조건, 키워드 규칙, 알림 방법(소리·진동·음성·화면 알림), 선택한 알림음, 중복 알림 막기 시간, 화면 테마
문자에 넣을 내 정보 사용자가 직접 입력한 문구(예: 차량번호·이름·연락처, 최대 100자). 입력하지 않으면 저장하지 않습니다.
가려진 알림 시각 Android가 내용을 가려서 보낸 알림을 마지막으로 받은 시각. 가려진 알림의 내용은 앱이 받지 못하므로 저장하지 않습니다.

이 정보는 앱 전용 저장소에 보관하며 다른 앱은 읽을 수 없습니다. Android 백업(Google 드라이브)과 새 기기로의 데이터 이전에도 포함하지 않습니다. 원본 알림으로 이동하기 위한 연결 정보와 같은 내용의 중복 알림을 막기 위한 비교 정보는 앱이 실행 중인 동안 메모리에만 잠시 두고 저장하지 않습니다.

3. 외부 전송과 제3자 제공

앱에는 인터넷 권한이 없으므로 어떤 정보도 서버나 외부로 전송하지 않습니다. 개인정보를 제3자에게 제공하거나 처리를 위탁하지 않으며, 개발자도 사용자의 알림과 설정을 볼 수 없습니다.

4. 다른 앱과의 연동

아래 동작은 사용자가 직접 켜거나 누를 때만 일어납니다.

  • 전화 버튼: 알림 본문에서 찾은 번호를 기기의 전화 앱에 채워 넣습니다. 전화는 사용자가 전화 앱에서 직접 걸어야 합니다.
  • 문자 버튼: 알림 본문에서 찾은 번호와 사용자가 입력한 내 정보를 기기의 문자 앱에 채워 넣습니다. 문자는 사용자가 문자 앱에서 직접 보내야 합니다.
  • 화면 알림: 조건에 맞은 알림의 경로·운임·본문을 기기의 알림창에 표시합니다. 잠금화면에서는 내용을 가리고, 1시간이 지나면 자동으로 지웁니다. 알림창의 내용은 사용자가 알림 접근을 허용한 다른 앱(예: 스마트워치 앱)도 읽을 수 있습니다.
  • 원본 알림 열기: 해당 알림을 보낸 앱(카카오톡)의 화면을 엽니다.
  • 음성으로 읽기: 기기에 설치된 음성 합성(TTS) 엔진에서 네트워크 연결이 필요 없는 음성만 사용합니다. 화물 조건에 맞은 알림은 연락처를 뺀 요약을, 키워드에만 맞은 알림은 연락처를 포함한 본문을 소리 내어 읽으므로 주변 사람이 들을 수 있습니다.
  • 알림음 선택: Android 시스템의 알림음 선택 화면을 사용합니다.
  • 설정 화면 열기: 알림이 오지 않을 때 확인할 수 있도록 좋아알림의 배터리 설정, 카카오톡의 알림 설정 같은 Android 설정 화면을 엽니다. 앱은 설정 화면을 열기만 하고 값을 바꾸지 않습니다.

5. 접근 권한

권한구분사용 목적
알림 접근 필수 선택한 앱의 알림 본문을 읽어 조건에 맞는지 판단
진동 필수 조건에 맞는 알림을 진동으로 알림
알림 표시 선택 조건에 맞는 알림을 화면 알림으로 표시(Android 13 이상에서 요청)

알림 접근은 Android 설정 > 알림 > 기기 및 앱 알림(기기마다 이름이 다를 수 있음)에서 언제든 해제할 수 있습니다. 해제하면 앱은 새 알림을 받지 못하며 알림 필터 기능이 동작하지 않습니다. 알림 표시는 허용하지 않아도 소리·진동·음성 알림은 동작합니다.

6. 보관 기간과 삭제

  • 최근 알림 이력은 100건까지만 보관하며, 넘으면 오래된 것부터 자동으로 지웁니다.
  • 앱 홈의 최근 알림에서 모두 지우기를 누르면 이력을 즉시 지웁니다.
  • 설정의 문자에 넣을 내 정보에서 문구를 지우고 확인하면 즉시 지웁니다.
  • 앱을 삭제하거나 Android 설정에서 좋아알림의 저장공간 데이터를 삭제하면 이력과 설정이 모두 지워집니다.

모든 정보가 사용자 기기에만 있으므로 개발자는 이를 열람하거나 대신 삭제할 수 없습니다.

7. 처리방침 변경

앱의 정보 처리 방식이 바뀌면 이 페이지를 고치고 시행일을 갱신합니다. 외부 전송이 생기는 등 중요한 변경은 앱 업데이트 전에 이 페이지에 먼저 알립니다.
