# joastudio.github.io

좋아스튜디오(JOASTUDIO) 공식 홈페이지. GitHub Pages로 `https://joastudio.github.io/`에 배포된다.

## 구조

| 경로 | 내용 |
| --- | --- |
| `/` | 앱 목록 (`index.html`) |
| `/alert/privacy/` | 좋아알림 개인정보 처리방침 |
| `/viewer/` | 좋아뷰어 사이트 — 별도 저장소 `joastudio/viewer` |
| `/app-ads.txt` | AdMob 인증 파일. 위치·내용을 바꾸지 않는다 |

- 공용 스타일은 `assets/site.css` 한 파일이다. 색은 좋아뷰어 사이트 토큰을 따른다.
- 앱 경로 이름(`alert`, `viewer`)과 같은 이름의 저장소에 Pages를 켜면 그 저장소가 이 폴더를 가린다.
- Play Console에 등록한 처리방침 URL은 경로를 바꾸지 않는다.
